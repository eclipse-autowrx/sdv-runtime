# 01-basic: Hello World C++ Compilation

Learn the basic C++ compilation endpoint with a simple Hello World example.

## Files
- `main.cpp` - Simple Hello World program
- `test-basic.js` - WebSocket test script

## What You'll Learn
- Basic `compile_cpp` endpoint usage
- Response format and status values
- Real-time compilation output
- Success/error handling

## Quick Test
```bash
# Run the test script
node test-basic.js

# Expected output:
# 🔨 Compiling C++ code...
# ✅ Build completed with code 0
# 🚀 Hello from C++!
```

## Frontend Integration
Copy the WebSocket code from `test-basic.js` into your frontend:
- File preparation
- Socket emission
- Response handling
- Output display
