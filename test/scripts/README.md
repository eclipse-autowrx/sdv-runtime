# Test Scripts - Ready to Use

Copy these working examples into your frontend application.

## Scripts
- `basic-test.js` - Simple Hello World test
- `connection-test.js` - Test WebSocket connection only
- `frontend-example.js` - Complete frontend integration example

## Usage
```bash
# Test connection
node connection-test.js

# Run basic compilation
node basic-test.js

# See full frontend integration
node frontend-example.js
```

## Integration Notes
- All scripts use `socket.io-client`
- Real error handling included
- Progress tracking examples
- Ready for React/Vue/Angular integration
